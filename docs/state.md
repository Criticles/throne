# Состояние проекта (общая сводка для всех каналов)

Этот файл читают **обе** сессии — десктопная и телеграмная. Он короткий и всегда актуальный:
если что-то поменялось, правьте его в том же коммите, что и код.

## Как работаем в двух каналах

Hermes не умеет вести один и тот же диалог одновременно на двух поверхностях: у каждой свой
`session_id`, и ходы сериализуются. Поэтому правило:

1. **Перед любой правкой**: `git pull` → `git status` → `git log --oneline -5`.
   Если в дереве есть чужие незакоммиченные файлы — это второй канал, не перезаписывать,
   а сначала сохранить их отдельным коммитом.
2. **Коммит после каждого куска работы**, пушить сразу. Долгих «незакоммиченных» периодов не бывает:
   именно так уже один раз чуть не потерялись правки маршрутизации.
3. Перед стартом сессии — прочитать этот файл. После крупного шага — обновить раздел «Где мы».
4. Передать диалог на другую поверхность можно: из CLI `/handoff telegram` (та же сессия,
   весь транскрипт), обратно — `/resume <название>`.

## Что уже сделано

- Пинг: все серверы в одном конфиге, у каждого свой пробный вход; WireGuard/AWG/WARP — там же
  (endpoint можно назвать в `route.rules[].outbound`), probe по IP-литералу `https://1.1.1.1/cdn-cgi/trace`.
- Xray — второе ядро, поднимается вместе с sing-box, общий конфиг на все XHTTP-профили
  (по socks-входу на сервер), меряется параллельно.
- WireTurn/Turnable — в конце серии, транспорт на каждого свой, лимит 8 VK-авторизаций.
- Отмена пинга закрывает строки («отменено»), спиннеры не остаются.
- Маршрутизация: профиль = папки с атрибутами; меню значений всплывает поверх формы;
  `reject` — значение пикера «Куда пускать»; одиночные атрибуты заменяют значение, `rule_set` копит.
- Соединения: троеточие (Пауза/Продолжить, Фильтр, Скопировать, Экспорт в txt), опрос только
  пока экран на виду.
- Серверы: единый кегль названий с полом 12,5 pt, дальше обрезка; папки с одинаковыми именами.
- Один `.sheet` на экран во всех экранах (iOS 15 иначе открывает только последний).

## Открытые вопросы

- **«Соединения» — вылет.** Симптом от пользователя: при входе на вкладку приложение/экран
  пропадает. Убраны `Timer.publish` (заменён на `Task` в `onAppear`/`onDisappear`), неиспользуемый
  `@EnvironmentObject RuleStore` из детального вида, список ограничен 400 строками. Если повторится —
  нужен `Throne-*.ips` из «Настройки → Конфиденциальность → Аналитика → Данные аналитики».
- **WARP (☁️ apteka / rutube)** не поднимается: в логе ядра `sending handshake initiation` без ответа.
  На настольном Throne те же два профиля падают так же (`context deadline exceeded`) — подписка/ключи,
  не наше ядро. В журнале приложения печатается `узел: <хост> → <ip>` для проверки.
- **Хвост Turnable**: 4 профиля по ~10 с каждый (VK-авторизация + капча на каждый). Параллелить
  нельзя без отдельного порта транспорта и отдельного экземпляра ядра на профиль.
- **Протоколы**: разбираются 9 типов (VLESS, VLESS XHTTP/Xray, Hysteria2, Mieru, WireGuard,
  AmneziaWG, WireTurn, Turnable, JSON подписки). Из списка Throne не хватает Shadowsocks, Trojan,
  VMess, TUIC, Hysteria, AnyTLS, Snell, ShadowTLS, MASQUE, SSH, OpenVPN, DNSTT, chaining, extra core.
  Дешёвые в добавлении: Trojan, Shadowsocks, VMess, TUIC, AnyTLS (sing-box уже умеет, нужен парсер
  ссылки и сборка outbound).
