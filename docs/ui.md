# Экраны

## Серверы (главная)

- **Карточка подключения**: имя выбранного сервера (не меняется во время пинга), бейдж
  протокола, страна · выходной IP · пинг, ниже трафик этого подключения и время аптайма.
  Кнопка питания справа. При ошибке — причина и кнопка «Журнал».
- **Подключиться к быстрому**: кнопка на всю ширину, под ней имя сервера + протокол,
  ниже страна и пинг.
- **Папки**: горизонтальные чипы «Все» + по одной на подписку, с количеством серверов.
- **Строка списка**: название (с точечками при переполнении) → бейдж протокола →
  «Пинг» + флаг/код страны/мс (или IP). После теста скорости добавляется четвёртая строка
  `↓ … · ↑ … Мбит/с`. Кружок выбора — по центру слева.
- **Заголовок списка**: название папки, `всего/активных`, четыре кнопки — отмена
  пинга/скорости, пинг всех, обновление подписки, сортировка. Ниже — «Трафик за всё время».
- **Долгое нажатие** — «Сведения»: пинг, скорость, трафик за всё время с кнопками обновления,
  параметры сервера (протокол, хост, порт, транспорт, SNI, flow, obfs, для WireTurn — TURN и MTU).
- **«Изм»** — подписки: добавить (+), порядок перетаскиванием, настройки подписки по нажатию
  (имя/папка, автообновление и интервал, копировать ссылку, `throne://`, QR, обновить, удалить).
  Галочка справа сохраняет и закрывает.

## Маршрут

- **Маршрутизация** — вход в профили правил, под кнопкой подпись «активно: <профиль>».
- Режимы: «По правилам», «Кроме России», «Всё в VPN».
- Общий outbound, обход локальной сети, блокировка рекламы.
- Гео-списки (geoip.dat, geosite.dat) со скачиванием и «Добавить свой список».
- Выбор VLESS-профилей для Xray.

## Маршрутизация

Две вкладки:

- **Упрощённая** — четыре списка по строкам: Напрямую / Прокси / Блокировать / WARP-bypass.
- **Расширенная** — записи «атрибут → значение» с целью `proxy` / `direct` / `reject` /
  конкретный сервер; атрибуты выбираются из списка (`domain`, `domain_suffix`,
  `domain_keyword`, `domain_regex`, `rule_set`, `process_name`, `package_name`, `protocol`,
  `network`, `ip_cidr`, `source_ip_cidr`, порты, `inbound`, `wifi_ssid` и другие).
- Экспорт и импорт — JSON или ссылка `throne://route`.

## Соединения

- Суммарный ↑/↓ по живым соединениям.
- «Какое правило поймает адрес» — проверка домена или IP по профилю.
- Список соединений: хост, через какой outbound, правило, объём. Данные из Clash API.

## Настройки

- **Ядра**: sing-box (версия из фреймворка), форк, Xray, Turnable; состояние с активным ядром.
- **Протоколы при импорте** — кнопка со списком.
- **Подписки** — карточки со сроком, трафиком и датой обновления.
- **DNS и туннель** — DoH/DoT, стек TUN, MTU, IPv6.
- **Пинг и скорость** — адрес пинга, зеркала скачивания и отдачи, объём теста.
- **Уведомления** — напоминание за 3 дня до конца подписки, ближайшее окончание с названием.
- **Журнал** и **Проверка обновлений ядер**.
- **Системный VPN** — вход в Network Extension-режим.
