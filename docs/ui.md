# Экраны

## Серверы (главная)

- **Карточка подключения**: имя выбранного сервера (не меняется во время пинга), бейдж
  протокола, страна · выходной IP · пинг, ниже трафик этого подключения и время аптайма.
  Кнопка питания справа. При ошибке — причина и кнопка «Журнал».
- **Подключиться к быстрому**: кнопка на всю ширину, под ней имя сервера + протокол,
  ниже страна и пинг.
- **Папки**: горизонтальные чипы «Все» + по одной на подписку, с количеством серверов.
- **Строка списка** (во всю ширину экрана, три строки): название → бейдж протокола →
  после пинга флаг, страна по-русски и выходной IP. Справа по центру — «Пинг»: после
  замера на его месте цифра (нажатие повторяет тест), после теста скорости она
  поднимается, а под ней появляется `↓ … · ↑ …`. Если пинг не прошёл — «Недоступен»
  красным вместо подробностей (они в «Сведениях» и журнале). Кружок выбора — по центру слева.
- **Заголовок списка**: название папки, `всего/активных`, четыре кнопки — отмена
  пинга/скорости, пинг всех, обновление подписки, сортировка. Ниже — «Трафик за всё время».
- **Долгое нажатие** — «Сведения»: пинг, скорость, трафик за всё время с кнопками обновления,
  параметры сервера (протокол, хост, порт, транспорт, SNI, flow, obfs, для WireTurn — TURN и MTU).
- **«Изм»** — подписки: добавить (+), настройки подписки по нажатию
  (имя/папка, автообновление и интервал, копировать ссылку, `throne://`, QR, обновить, удалить).
  Свайп влево — удалить. Галочка справа сохраняет и закрывает.
- **Добавление подписки** спрашивает, куда её положить: в новую папку или в текущую
  (активную). Одну и ту же ссылку можно добавить несколько раз — папки не сливаются,
  потому что папка входит в ключ дедупликации серверов.

## Маршрут

- **Профили маршрутизации** — список профилей: создать, дублировать, сделать активным,
  удалить, импорт из буфера (JSON/`throne://route`, формат определяется сам),
  экспорт JSON или `throne://route`. Активный профиль помечен галочкой.
- **Редактор профиля**: название, общий outbound, вид — упрощённый или расширенный.
  Упрощённый: четыре списка доменов. Расширенный: записи по порядку.
- **«Добавить запись»** сразу открывает полный список атрибутов (ip_version, network,
  protocol, inbound, domain*, source_ip*, ip_cidr, порты, process*, package_name, wifi*,
  rule_set, invert, outbound, override_*, tls_spoof*, method, no_drop, strategy) с поиском
  и подсказкой к каждому. Атрибут требует выбора — есть «Выбрать»; пишется текстом —
  нажатие на название открывает экран значения с подсказками. У записи выбирается,
  куда её направить (proxy / direct / reject / сервер).
- **Предварительный просмотр JSON** снизу — ровно тот JSON, который уйдёт при экспорте.
- Режимы: «По правилам», «Кроме России», «Всё в VPN» — режим и его пояснение в одной строке.
- Общий outbound, обход локальной сети, блокировка рекламы.
- Гео-списки (geoip.dat, geosite.dat) со скачиванием и «Добавить свой список».
- Выбор VLESS-профилей для Xray.

## Маршрутизация

Две вкладки:

- **Упрощённая** — четыре списка по строкам: Напрямую / Прокси / Блокировать / WARP-bypass.
- **Расширенная** — записи «атрибут → значение» с целью `proxy` / `direct` / `reject` /
  конкретный сервер; атрибуты выбираются из списка (`domain`, `domain_suffix`,
  `domain_keyword`, `domain_regex`, `rule_set`, `process_name`, `package_name`, `protocol`,
  `network`, `ip_cidr`, `source_ip_cidr`, порты, `inbound`, `wifi_ssid` и другие).
- Экспорт и импорт — JSON или ссылка `throne://route`.

## Соединения

- Сводка: суммарный ↑/↓, число соединений, время обновления.
- Фильтр: поиск по домену/IP/порту, сеть (tcp/udp), правило (из живого списка).
- Строка соединения: адрес и порт, длительность, источник и протокол, сеть и процесс,
  объём, сработавшее правило, outbound.
- Нажатие открывает «Соединение»: домен, IP и порт — каждое нажатие ведёт в маршрутизацию,
  где адрес добавляется записью в выбранный профиль и выбранное правило.

## Настройки

- **Ядра**: sing-box (версия из фреймворка), форк, Xray, Turnable; состояние с активным ядром.
- **Протоколы при импорте** — кнопка со списком.
- **Подписки** — карточки со сроком, трафиком и датой обновления.
- **DNS и туннель** — DoH/DoT, стек TUN, MTU, IPv6.
- **Пинг и скорость** — адрес пинга, зеркала скачивания и отдачи, объём теста.
- **Уведомления** — напоминание за 3 дня до конца подписки, ближайшее окончание с названием.
- **Журнал** и **Проверка обновлений ядер**.
- **Системный VPN** — вход в Network Extension-режим.
