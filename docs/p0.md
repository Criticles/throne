# Фаза P0 — скелет и доказательство связки

## Цель

Один прогон CI и одна установка на телефон должны доказать четыре вещи:

1. `experimental/libbox` из форка `throneproj/sing-box` собирается под iOS (`arm64`) через gomobile.
2. `NEPacketTunnelProvider` получает файловый дескриптор utun и отдаёт его ядру.
3. sing-box стартует внутри расширения, поднимает TUN и пропускает трафик (`direct`-outbound).
4. Подпись/установка работают — либо через TestFlight по секретам, либо переподписью неподписанного `.ipa`.

## Что уже в репозитории

| Файл | Роль |

| `ios/Shared/P0Config.swift` | минимальный конфиг sing-box (TUN + direct + DNS) |
| `.github/workflows/ios.yml` | сборка `.ipa`, опциональная подпись и загрузка в TestFlight |
| `scripts/build_ios.sh` | то же локально на macOS |

## Порядок запуска

1. `docs/apple-setup.md` — аккаунт, App ID, сертификат, секреты.
2. GitHub → Actions → **iOS** → *Run workflow*.
3. Скачать артефакт `Orbita-unsigned.ipa` (или дождаться сборки в TestFlight).
4. Установить на телефон, нажать Connect, разрешить VPN.
5. Проверить лог в приложении: `libbox version`, `tunnel settings applied`, `service started`.

## Что НЕ входит в P0

- Никаких протоколов и серверов: outbound — `direct`, то есть проверяется TUN, а не прокси.
- Нет Xray, нет Turnable, нет подписок, нет роутинга (кроме `final: direct`).
- Нет мониторинга памяти сверх `LibboxSetMemoryLimit(true)` — базовый замер делаем в конце P0
  (Xcode → Debug → Memory, процесс `PacketTunnel`; цель < 30 МБ на пустом конфиге).

## Известные ограничения и риски P0

- **Код не скомпилирован.** У меня нет macOS/Xcode, поэтому первая сборка в CI почти наверняка
  покажет ошибки. Сверено по исходникам форка (`experimental/libbox`): `SetupOptions` и его поля,
  `Setup`, `NewCommandServer`, `CommandServer.Start/Close/StartOrReloadService(config, options)`,
  `SetMemoryLimit`, `Version`. Не сверено: имена, которые генерирует gomobile для итераторов TUN
  (`getInet4RouteAddress` и соседние) и для protocol-методов — если разойдутся, правятся по логу.
- **`GetTunnelFileDescriptor`** — рабочий путь (так делает sing-box-for-apple), но если он вернёт −1,
  остаётся KVC-фолбэк `packetFlow.value(forKeyPath: "socket.fileDescriptor")`; оба варианта в коде.
- **Entitlement** проверяется только на подписанной сборке: неподписанный `.ipa` после переподписи
  без Network Extension просто не покажет VPN-профиль.
- **Тег `with_low_memory`** включён в сборку; если в форке такого тега нет — Go его просто
  проигнорирует, ошибки не будет.
